# Upload your profile photo here

Upload a single photo to this folder (`photo-input/`) to update the ASCII portrait shown on your GitHub profile.

- Supported formats: JPG, JPEG, PNG, WEBP, BMP.
- The latest uploaded/committed image is used.
- The GitHub Actions workflow converts it into an animated terminal-style SVG at `assets/avi-ascii.svg`.
- Wait for the **Update ASCII profile portrait** workflow to finish; it commits the generated portrait automatically.
- You do not need to edit the README.

Tip: use a clear, well-lit face photo. If several photos are in the folder, remove old ones to avoid ambiguity.
